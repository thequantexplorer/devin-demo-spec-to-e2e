# acme-kanban

The internal team board. Express API + vanilla JS drag-and-drop UI, stored in `data/board.json`.

```sh
npm install
npm start     # http://localhost:3100
npm test
```

Feature specs live in `docs/specs/`.

---

This repo is a starter for a Devin demo. See [DEVIN_DEMO.md](DEVIN_DEMO.md) for setup and the prompt.
